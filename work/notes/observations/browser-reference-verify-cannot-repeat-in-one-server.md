# The browser reference's verify suite cannot be repeated within one Vite server

Observed 2026-09-28 while fixing `a-browser-app-queries-its-worker-with-graphql`, running `pnpm --filter browser-reference exec playwright test --repeat-each 2` (chromium): the first round of 8 passes, then every test of the second round fails with `#transfers` showing `10` instead of `5`. The likely cause is `verify/reference.spec.ts` "an edited processor is swapped in by the worker" (line ~283), which rewrites `src/processor.ts` to add 2 per transfer and restores it, while the same Vite server (started once per invocation) keeps serving the edited module to later pages. Separate invocations pass every time, so CI (one run) is unaffected, but `--repeat-each` over the whole file is not a usable flake check; repeat a single test with `-g` instead.
